## 3. Индивидуальный проект

Название проекта: «Система учета кухонного инвентаря». Предметная область: предметы кухни, категории, состояния, помещения и перемещения инвентаря. Работа продолжает проект, переведенный на ORM в ПР9.

На ПР10 подключена административная панель Django и зарегистрированы все пять предметных моделей. Настроены русские названия, столбцы, поиск, фильтры, сортировка и количество записей на странице. В карточках отображаются связанные предметы и история перемещений через inline.

Для перемещений введены статусы TextChoices: PLANNED, COMPLETED, CANCELLED и методы QuerySet active(), completed(), cancelled(), for_date(). Миграция данных преобразует старое поле cancelled до его удаления, сохраняя смысл исторических записей.

Добавлены GeneratedField для стоимости партии, английский slug и get_absolute_url() для помещений, контекстный процессор общих данных сайта. Настроены права доступа и безопасные действия Admin; проверены запросы через Django Debug Toolbar.

Git-репозиторий: https://github.com/maximqpir-beep/kitchen-inventory

## 4. Результат работы

В результате выполнения ПР10 административная панель позволяет просматривать и управлять данными проекта с учетом прав пользователя. Настройки размещены в apps/items/admin.py и apps/movements/admin.py. Пароль суперпользователя задается локально командой createsuperuser.

Изменения статусов выполняются через общие сервисы с проверкой исправности предмета, текущего помещения и порядка отмены. Уникальное ограничение базы запрещает два активных плана одной партии на одну дату. Выполненные и отмененные записи не блокируют новое планирование.

В настоящем браузере Debug Toolbar показал 5 запросов каталога: COUNT для пагинации, выборку предметов с JOIN и три справочника. Повторные запросы к связанным объектам N+1 отсутствуют. Реальные скриншоты Admin, поиска, inline, журнала, статистики и SQL-панели приложены в reports/PR10/screenshots/.

Проверка версии ПР10: python manage.py check — без замечаний; миграции применены, новых изменений моделей нет; pytest — 75 тестов прошли; flake8 — без замечаний. Проверены преобразование данных, статусы, GeneratedField, slug, права доступа и действия Admin. README.md обновлен, результат сохранен отдельным коммитом.
