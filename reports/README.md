# Отчеты по практикам

Каждая практика находится в своей папке PR<номер>/:
REPORT.pdf — готовый отчет, REPORT.md — редактируемый текст.
У ПР10 и ПР11 внутри есть screenshots/ с реальными снимками браузера.
checks.txt — журнал проверки проекта.

Отчеты описывают версии на момент выполнения практик. После переупорядочивания
путей текущие модели/формы находятся в apps/, настройки — в config/.
Соответствие вопроса преподавателя и актуального файла: ../DEFENSE_MAP.md.
