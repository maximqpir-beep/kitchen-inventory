## 3. Переработка шаблонов
В settings.py настроен каталог templates уровня проекта. Создан base.html с блоками title и content. Общие навигация и footer вынесены в templates/includes. Шаблоны приложений размещены с пространствами имен: homepage/templates/homepage, items/templates/items и movements/templates/movements.

Дочерние страницы наследуют base.html через extends. Включаемая карточка предмета и фрагменты состояний подключаются через include с явной передачей объекта. View-функции готовят контекст и вызывают render(); сборка HTML-строк и функция page() удалены. Формирование разметки и подготовка данных разделены.

Списки выводятся циклом for, отсутствие элементов обрабатывается empty. Условия if/elif/else определяют оформление исправного, требующего ремонта и списанного инвентаря. Статус перемещения зависит от свойства cancelled. Шаблоны обращаются к атрибутам и методам объектов ПР3; правила учета остаются в предметной модели.

## 4. URL, фильтры и static
Сохранены адреса ПР5: /, /items/, /items/<id>/, /movements/, /movements/<id>/. Ссылки формируются через тег url и пространства имен homepage, items, movements. Карточка перемещения связана ссылкой с карточкой предмета. Собственные 404 и 503 также переведены на шаблоны.

Использованы фильтры length для количества результатов, default для отсутствующего значения, truncatechars для длинного названия, stringformat для номера и date для даты. Дополнительный фильтр money форматирует целые копейки без преобразования в float. ISO-строка времени передается в шаблон как datetime.

Через load static и static подключены локальный Bootstrap, собственный CSS, SVG-логотип, иллюстрация кухонного инвентаря и JavaScript. Скрипт catalog.js переключает сетку карточек между обычным и компактным видом, меняет текст кнопки и aria-pressed. Без JavaScript каталог и серверный поиск остаются доступными.

## 5. Результат и проверки
Пять страниц используют единый каркас и навигацию. JSON-формат, консольное меню и классы Item, Category, Condition, Room, Movement сохранены. Веб-интерфейс предназначен для просмотра; ORM и веб-формы редактирования не внедрялись. README обновлен, порядок запуска и перехода от ПР5 описан.

manage.py check завершился без замечаний. Все 73 теста pytest прошли, включая прежние проверки предметной модели и веб-интерфейса, использование base.html, контекст с объектами, фильтры, наличие ресурсов и отсутствие генерации HTML во views. flake8 завершился без замечаний; синтаксис JavaScript проверен.

Проверены запуск сервера, ответы основных страниц, доступность CSS, SVG и JavaScript по HTTP, а также оформленная 404 при DEBUG=False. Автоматический браузер в среде подготовки не запустился: внешний вид на компьютере и телефоне и переключение компактного вида необходимо проверить вручную перед защитой.
