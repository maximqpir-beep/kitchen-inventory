# Система учета кухонного инвентаря

Практическая работа № 1. Группа ЭФБО-12-24.

## Назначение и пользователи
Программа предназначена для учета кухонного инвентаря в столовой или ресторане. Пользователи: кладовщик, повар и заведующий кухней.

## Предметная область
Учет предметов, их состояния и размещения на кухне. Основные сущности: предмет, категория, состояние и помещение.

## Возможности
- Выбор одного из 8 предметов по номеру.
- Проверка пригодности предмета к использованию.
- Расчет стоимости партии по количеству и цене.
- Перемещение исправной партии в другое помещение.

## Запуск
Нужен Python 3.10 или новее. Дополнительные библиотеки не требуются.

```bash
python main.py
```

## Как пользоваться
1. Выбрать предмет цифрой от 1 до 8.
2. Ввести количество от 1 до 10000.
3. Выбрать состояние и помещение назначения по номеру.
4. Посмотреть результат и нажать Enter для возврата в меню.
5. Для выхода ввести 0 в меню предметов.

Каждый выбор начинает новую партию в горячем цехе. Данные между выборами и после закрытия программы не сохраняются.
