# Кухонный учет — ПР5

Система учета кухонного инвентаря. Группа ЭФБО-12-24.
Для кладовщика, повара и заведующего кухней: предмет, категория, состояние, помещение и история перемещений.

## Запуск в Windows
Нужен Python 3.10 или новее. Открой терминал в этой папке, рядом с `manage.py`:

```bash
py -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
./.venv/Scripts/python.exe manage.py check
./.venv/Scripts/python.exe manage.py runserver
```

Открой http://127.0.0.1:8000/ в браузере. Терминал оставь открытым; остановка сервера — Ctrl+C. На Linux/macOS используй `python3 -m venv .venv` и путь `./.venv/bin/python`.

## Страницы
| URL | Назначение |
|---|---|
| `/` | Обзор и статистика |
| `/items/` | Каталог и поиск по названию |
| `/items/2/` | Карточка предмета с ID 2 |
| `/movements/` | Журнал перемещений |
| `/movements/1/` | Карточка перемещения с ID 1 |

Все страницы связаны навигацией. Неверный ID дает 404. Если JSON недоступен или поврежден — ответ 503; исходный файл не перезаписывается.

## Данные и консоль
Классы и JSON сохранены из ПР3. Сайт читает `data/inventory.json` и показывает объекты `Item`, `Category`, `Condition`, `Room`, `Movement`. В учебном наборе 8 партий, 3 перемещения (одно отменено), разные состояния. Цена хранится в копейках.

Для добавления, перемещения и изменения предметов запусти прежнее меню:

```bash
./.venv/Scripts/python.exe main.py
```

После изменения обнови страницу браузера. Через сайт на ПР5–ПР6 доступен только просмотр и поиск. ORM, база данных, формы и авторизация появятся позже; `migrate` сейчас не требуется.

## Структура
`kitchen_site/` — настройки, главный маршрутизатор и чтение данных. `homepage/`, `items/`, `movements/` — Django-приложения. `models/`, `inventory.py`, `storage.py`, `main.py` — сохраненная предметная логика ПР3. `tests/` — проверки.

HTML создается через `HttpResponse` и функцию `page()` в `homepage/html.py`.

Bootstrap и собственный CSS лежат в `homepage/static/homepage/`. Они работают без CDN. В ПР6 там также находятся SVG-изображения и `js/catalog.js`.

## Проверки
```bash
./.venv/Scripts/python.exe -m pytest -q
./.venv/Scripts/python.exe -m flake8
```

Результат подготовки: 64 теста прошли, `check` и flake8 — без замечаний. Тесты не изменяют рабочий JSON.

Для показа оформленной 404 останови обычный сервер и запусти локальный демонстрационный режим:

```bash
./.venv/Scripts/python.exe manage.py runserver --settings=kitchen_site.settings_demo --insecure
```

Открой `/unknown/`. В этом режиме DEBUG=False, а `--insecure` разрешает встроенному серверу отдавать локальные CSS и изображения. Это команда для учебной демонстрации, не для публикации сайта.
