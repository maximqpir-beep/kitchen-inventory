# Система учета кухонного инвентаря — ПР2

Группа ЭФБО-12-24. Программа для кладовщика, повара и заведующего кухней.
Учитывает предмет, категорию, состояние и помещение.

## Возможности
Просмотр, добавление партии, поиск и фильтры, сортировка, проверка пригодности, расчет стоимости, перемещение, отмена перемещения, изменение состояния и статистика. Управление по цифрам; Enter возвращает в меню, 0 завершает работу.

## Запуск
Python 3.10 или новее. В терминале в папке проекта:

```bash
py main.py
```

На Linux/macOS вместо `py` используй `python3`. Для самой программы сторонние пакеты не нужны.

## Правила
В комплекте 8 учебных партий по одной штуке. Новые партии добавляются через пункт 2: там указываются количество и цена. Перемещается вся партия. Перемещение разрешено только для исправной партии в другое помещение. Списание окончательно. Отмена исправляет запись журнала и возвращает предыдущее помещение; отменять можно только последнее неотмененное перемещение выбранной партии.

## Хранение
Изменения автоматически записываются в `data/inventory.json` и восстанавливаются при запуске. При ошибке сохранения операция отменяется. Поврежденный файл не перезаписывается. Путь определяется относительно программы, а не терминала. Одновременная работа нескольких копий с одним файлом не поддерживается.

JSON содержит `version`, список `items` и журнал `moves`. У предмета: `id`, `name`, `category_id`, `state_id`, `room_id`, `quantity`, `unit_price` (целые копейки). У перемещения: `id`, `item_id`, `from_room`, `to_room`, `created_at`, `cancelled`. Справочники заданы в `catalog.py`.

## Файлы
- `main.py` — меню; `utils.py` — ввод.
- `inventory.py` — операции и обработка коллекций.
- `catalog.py` — справочники и учебные данные.
- `storage.py`, `validation.py` — JSON и проверка данных.
- `tests/` — автоматизированные тесты.
- `REPORT.pdf`, `REPORT.md` — отчет и редактируемый исходник.
- `DEFENSE.md` — ответы и пример отладки.

## Проверка

```bash
py -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest -q
.venv/Scripts/python -m flake8
```

На Linux/macOS путь к интерпретатору окружения: `.venv/bin/python`.
