# Подготовка к защите ПР2

Группа ЭФБО-12-24. Тема: система учета кухонного инвентаря.

## Отладка в IDE
1. Выбери интерпретатор Python и открой main.py.
2. Поставь точку останова на return item["quantity"] * item["unit_price"] в inventory.py.
3. Запусти Debug и выбери пункт 1. При расчете первой партии проверь количество 1, цену 125050 и результат 125050 коп.
4. Выполни шаг, затем продолжи выполнение. Для партии из 3 кастрюль стоимость должна составить 375150 коп.
5. Для упражнения временно замени умножение на сложение, найди неправильный результат пошагово, верни умножение и повтори тесты.

## Контрольные вопросы

1. **Коллекции Python.** list — изменяемая последовательность; tuple — неизменяемая; set — уникальные элементы; dict — пары ключ–значение. В catalog.py используется кортеж примеров, в inventory.py — списки, словари и множество категорий.

2. **Список и кортеж.** Список можно изменять после создания, кортеж нельзя изменять поэлементно. Кортеж может содержать изменяемые объекты.

3. **Множество.** Подходит для удаления повторов, проверки принадлежности, пересечения и объединения. statistics считает уникальные категории через set.

4. **Словарь.** Значение извлекается по уникальному ключу. Например, item['quantity'] хранит количество партии.

5. **for и while.** for перебирает элементы итерируемого объекта, while повторяет действия, пока условие истинно. В main.py while поддерживает меню, for выводит предметы.

6. **range.** Создает последовательность целых чисел для перебора без хранения готового списка; range(3) дает 0, 1, 2.

7. **Перебор словаря.** for key in data перебирает ключи, data.values() — значения, data.items() — пары ключ–значение; пример — choose в utils.py.

8. **break и continue.** break завершает ближайший цикл; continue пропускает остаток текущей итерации и переходит к следующей. В main.py break используется для выхода.

9. **Объявление функции.** Функция объявляется через def. Без явного return возвращается None; пример — save_data.

10. **Позиционные и именованные аргументы.** Позиционные сопоставляются параметрам по порядку, именованные — по имени: find_items(data, room_id=3).

11. **Область видимости.** Определяет, где доступно имя. Поиск обычно идет по LEGB: локальная, внешних функций, глобальная, встроенная. Локальная переменная функции не становится глобальной.

12. **Docstring.** Строка документации в начале модуля или функции; доступна через __doc__ и help(). В проекте документированы модули и основные функции.

13. **Модуль.** Файл Python с определениями и исполняемым кодом. storage.py — модуль сохранения и загрузки.

14. **Варианты импорта.** import datetime требует datetime.date; from datetime import date позволяет обращаться к date напрямую.

15. **Пакет и __init__.py.** Пакет объединяет модули. __init__.py обозначает обычный пакет и может задавать его интерфейс. Пакеты пространств имен могут существовать без него; fridge_task — обычный пакет.

16. **try/except.** try содержит потенциально ошибочную операцию, except обрабатывает конкретную ошибку. main.py обрабатывает ValueError и OSError.

17. **finally и else.** else у try выполняется, если в блоке try не было исключения; finally выполняется при обычном выходе и при исключении. В storage.py finally удаляет временный файл.

18. **raise.** Явно возбуждает исключение при нарушении правила. move_item вызывает ValueError, если перемещение недоступно.

19. **Закрытие файла.** Освобождает файловый дескриптор и завершает работу буферов. Незакрытые файлы расходуют ресурсы и могут задерживать запись.

20. **Контекстный менеджер.** with управляет ресурсом и вызывает завершение контекста, в том числе при исключении. Файл закрывается автоматически.

21. **Интроспекция.** Изучение объекта во время исполнения: type(), isinstance(), dir(), getattr(), hasattr(), help(). Пример: type(data['items']) покажет list.

22. **Пространство имен.** Соответствие имен объектам, например глобальные имена модуля. Область видимости определяет, из каких участков кода к ним можно обратиться.

23. **Итератор и генератор.** Итератор возвращает элементы через next() и заканчивается StopIteration. Генератор — разновидность итератора; создается генераторной функцией или выражением. sum в statistics потребляет генераторное выражение.

24. **yield.** Возвращает очередное значение из генераторной функции и приостанавливает ее с сохранением состояния до следующего next(). В основном проекте вместо такой функции достаточно генераторных выражений.

25. **Lambda.** Короткая анонимная функция из одного выражения; sort_items использует lambda для ключа сортировки названий.

26. **Аннотации типов.** Документируют типы параметров и результата: calculate_total(item: dict) -> int. Сами по себе не проверяют значения во время исполнения.

27. **flake8.** Проверяет стиль PEP 8 и некоторые ошибки, например неиспользуемые импорты. Запуск: py -m flake8 из папки проекта после установки зависимостей.

28. **Оформление.** Отступы 4 пробела, осмысленные имена snake_case, модули по назначению, аннотации основных функций, отсутствие неиспользуемого кода и дублирования; длина строк до 79 символов.

29. **pytest и assert.** Тест — функция с именем test_*. assert проверяет условие; если оно ложно, тест падает с AssertionError. Пример — tests/test_inventory.py.

30. **Запуск тестов.** py -m pytest -q. passed — успешная проверка, failed — проверка не сошлась, error — ошибка подготовки или сбора. Для данной версии выполнено 45 тестов.

31. **Функции ПР2.** Просмотр и добавление партий, проверка состояния, расчет стоимости, перемещение и отмена, поиск, фильтры, сортировка, статистика и работа с JSON.

32. **Представление данных.** В памяти список словарей предметов и список словарей перемещений. В JSON верхние ключи version, items, moves; цены в копейках.

33. **Проверка доступности помещения.** В примере методички проверяется свободная дата помещения. В моей теме аналог — can_move: предмет исправен, помещение существует и отличается от текущего. Бронирование дат кухонному инвентарю не добавлялось.

34. **Исключения проекта.** ValueError — неверные числа, значения, JSON или действия; OSError — ошибки файлов; UnicodeError — неверная кодировка. EOFError и KeyboardInterrupt завершают интерфейс без сохранения незаконченного действия.

35. **Модули проекта.** catalog — справочники; inventory — операции; validation — проверка; storage — JSON; utils — ввод; main — меню; tests — проверки.

36. **Конструкции Python.** Списки, словари, множества, кортежи, comprehensions, for/while, функции, генераторные выражения, lambda, try/except/finally и with.

37. **Что изменится на ПР3.** Словари предметов станут Item, справочники — Category/Condition/Room, записи журнала — Movement. Поведение отдельного предмета станет методами, поиск по коллекциям останется функциями.

38. **Зачем файлы.** Переменные теряются после завершения процесса; JSON сохраняет сведения между запусками. В памяти данные все равно нужны для текущей работы.
