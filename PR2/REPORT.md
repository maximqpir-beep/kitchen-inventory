## 3. Доработка индивидуального проекта
Предметная область - учет кухонного инвентаря столовой или ресторана. Пользователи: кладовщик, повар и заведующий кухней. Сущности: предмет, категория, состояние, помещение и запись перемещения. Сценарии ПР1 сохранены: оценка пригодности, расчет стоимости и перемещение партии.

Данные представлены списками словарей. Добавлены просмотр нескольких партий, добавление новых, поиск по названию, фильтры по категории/состоянию/помещению, сортировка по названию или стоимости, изменение состояния, статистика и журнал перемещений. В меню используются цифровые команды и возврат после операции.

Начальный набор содержит восемь партий по одному предмету. При добавлении задаются количество и цена. Стоимость хранится в целых копейках. Исправная партия может перемещаться в другое помещение; списание окончательно. Ошибочную запись перемещения можно отменить, начиная с последней действующей записи выбранной партии.

## 4. Структура и хранение данных
main.py отвечает за меню, utils.py - за ввод, catalog.py - за справочники и учебные данные, inventory.py - за обработку коллекций, validation.py - за проверку, storage.py - за JSON. Каталог tests содержит проверки pytest. Классы предметной области на ПР2 не используются.

Файл data/inventory.json содержит version, items и moves. Предмет имеет ID, название, ID категории, состояния и помещения, количество и цену. Запись перемещения содержит ID предмета, два помещения, дату и признак отмены. Загрузка выполняется при запуске, сохранение - после успешного изменения. Для записи используется временный файл с последующей заменой основного; неудачная запись не меняет прежние данные.

## 5. Результаты проверки
Выполнены 45 тестов pytest: 38 проверок основного проекта и 7 проверок примера «Холодильник». Проверены добавление, расчет, поиск, фильтры, сортировка, статистика, перемещение и отмена, ограничения состояния, неверный ввод, поврежденный JSON, ошибка записи и восстановление после перезапуска. Все тесты прошли. flake8 завершился без замечаний; основные функции имеют аннотации типов.

В отладчике pdb установлена точка останова в calculate_total и проверен расчет партии из трех предметов по 125050 коп.: результат 375150 коп. Для демонстрации в IDE в DEFENSE.md приведены шаги установки breakpoint, просмотра переменных и исправления намеренной ошибки. Демонстрация на компьютере студента выполняется отдельно.

Контрольные данные: восемь исходных партий содержат восемь предметов пяти категорий; суммарная стоимость - 6550.50 руб. После перемещения ножа в помещение «Склад» новое размещение сохраняется между запусками.
